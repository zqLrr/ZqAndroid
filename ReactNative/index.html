    React Native 学习计划

    学习目标

    系统掌握 React Native 开发，重点覆盖 语法基础 和 性能优化 两大方向，能够独立开发、调试并优化一款跨端应用。

    时间投入

    • 工作日：每天 1 小时
    • 周末：每天 5 小时
    • 每周合计：约 15 小时
    • 总周期：10 周（约两个半月）

    学习路线总览

    阶段 周期 主题 重点
    第一阶段 第 1-2 周 基础语法 JavaScript / TypeScript、React 核心概念
    第二阶段 第 3-4 周 RN 核心语法 组件、样式、Hooks、事件、原生能力
    第三阶段 第 5-6 周 工程化与状态管理 导航、状态管理、网络、工程化
    第四阶段 第 7-8 周 性能优化 渲染优化、内存优化、启动优化、列表优化
    第五阶段 第 9-10 周 实战与总结 完整项目、性能调优、面试整理

    第一阶段：基础语法（第 1-2 周）

    第 1 周：JavaScript 核心

    天数 主题 内容
    Day 1 变量与作用域 var/let/const、作用域链、闭包
    Day 2 函数与 this 箭头函数、this 绑定、call/apply/bind
    Day 3 异步编程 Promise、async/await、事件循环
    Day 4 数组与对象 解构、展开运算符、常用高阶函数
    Day 5 ES6+ 新特性 模块化、可选链、空值合并、Map/Set

    周末任务：写一个 JS 小工具链（如待办列表的数据处理模块），完成 10 道手写题（Promise.all、节流防抖、深拷贝等）。

    第 2 周：TypeScript + React 核心

    天数 主题 内容
    Day 1 TS 基础 类型注解、接口、泛型基础
    Day 2 TS 进阶 联合类型、类型守卫、工具类型
    Day 3 React 组件 JSX、函数组件、Props、State
    Day 4 React 生命周期 useEffect、useLayoutEffect、依赖数组
    Day 5 React 状态提升 受控组件、Lifting State Up

    周末任务：用 TypeScript 重构上周的 JS 工具链；写一个 React 计数器 + 待办列表 Demo（使用 Vite + React）。

    关键知识点：闭包在 Hook 中的影响；this 在 React 事件处理中的行为；TypeScript 泛型在组件 Props 中的应用；依赖数组对 useEffect 的重要性。

    第二阶段：React Native 核心语法（第 3-4 周）

    第 3 周：核心组件与样式

    天数 主题 内容
    Day 1 环境搭建 Expo / React Native CLI 环境配置、真机调试
    Day 2 基础组件 View、Text、Image、TextInput、Button
    Day 3 列表组件 ScrollView、FlatList、SectionList、keyExtractor
    Day 4 样式系统 StyleSheet、Flexbox、响应式布局
    Day 5 平台适配 Platform API、安全区、屏幕尺寸

    周末任务：搭建一个 RN 项目骨架；实现一个首页列表页面（含网络图片、标题、描述）。

    第 4 周：Hooks、事件与原生能力

    天数 主题 内容
    Day 1 Hooks 回顾 useState、useEffect、useRef、useMemo、useCallback
    Day 2 自定义 Hook 封装网络请求 Hook、表单 Hook
    Day 3 事件处理 触摸事件、手势基础（Pressable、Touchable）
    Day 4 原生模块 调用相机、相册、定位、本地存储（AsyncStorage）
    Day 5 调试技巧 Metro、Flipper、Chrome DevTools、LogBox

    周末任务：实现一个带图片上传的定位打卡 Demo；用自定义 Hook 封装网络请求和本地缓存。

    关键知识点：FlatList 为什么比 ScrollView 性能更好；Flexbox 在 RN 中的默认值与 Web 不同；useCallback/useMemo 在子组件传递时的作用；原生模块的权限请求流程。

    第三阶段：工程化与状态管理（第 5-6 周）

    第 5 周：导航与状态管理

    天数 主题 内容
    Day 1 React Navigation Stack、Tab、Drawer 导航器配置
    Day 2 导航传参 参数传递、类型安全、返回处理
    Day 3 Context API 跨组件状态共享、主题/语言切换
    Day 4 Redux Toolkit Store、Slice、异步 Thunk
    Day 5 Zustand / Jotai 轻量状态管理方案对比

    周末任务：搭建一个多 Tab + 详情页的应用框架；实现主题切换和登录状态管理。

    第 6 周：网络请求与工程化

    天数 主题 内容
    Day 1 Fetch / Axios 封装请求拦截、错误处理、Token 刷新
    Day 2 数据缓存 SWR / React Query 基础使用
    Day 3 代码规范 ESLint、Prettier、TypeScript 严格模式
    Day 4 模块化 目录结构、路由配置、组件分层
    Day 5 打包发布 Android/iOS 打包、热更新概念

    周末任务：用 React Query 完成一个带下拉刷新、上拉加载的列表页；配置 ESLint + Prettier，整理项目目录结构。

    关键知识点：React Navigation 导航栈的生命周期；Context 的重新渲染问题；Redux vs Zustand 的适用场景；请求库的拦截器设计；代码分割与懒加载初步。

    第四阶段：性能优化（第 7-8 周）

    第 7 周：渲染性能与列表优化

    天数 主题 内容
    Day 1 渲染原理 JS Thread、UI Thread、Shadow Thread、Yoga
    Day 2 Re-render 优化 React.memo、useMemo、useCallback、key 优化
    Day 3 FlatList 优化 getItemLayout、windowSize、removeClippedSubviews
    Day 4 图片优化 懒加载、缓存、压缩、WebP、占位图
    Day 5 动画性能 Animated API、useNativeDriver、避免 JS 驱动动画

    周末任务：用 Flipper / Profiler 分析一个长列表的渲染瓶颈；实现一个优化后的图片瀑布流页面。

    第 8 周：启动性能、内存优化与监控

    天数 主题 内容
    Day 1 启动优化 包体积、预加载、SplashScreen、Hermes 引擎
    Day 2 内存优化 图片内存、泄漏排查、闭包泄漏、订阅清理
    Day 3 网络优化 请求合并、缓存策略、压缩、DNS 预解析
    Day 4 卡顿分析 Systrace、Performance Monitor、FPS 监控
    Day 5 监控方案 Sentry、Firebase Performance、自定义埋点

    周末任务：对比开启/关闭 Hermes 后的启动时间和包体积；做一次完整的内存泄漏排查实验。

    关键知识点：为什么长列表要用 FlatList 而不是 ScrollView；useNativeDriver: true 的作用和限制；Hermes 与 JSC 引擎的区别；图片内存占用计算与优化；避免匿名函数和内联对象导致的 re-render。

    第五阶段：实战与总结（第 9-10 周）

    第 9 周：完整项目实战

    项目建议（选一个）：

    1. 技术资讯阅读 App：列表、详情、收藏、搜索、主题切换
    2. 个人记账 App：表单、图表、本地存储、数据筛选
    3. 天气查询 App：定位、网络请求、下拉刷新、城市管理
    天数 主题 内容
    Day 1 需求拆解 页面结构、数据流、技术选型
    Day 2 项目搭建 导航、状态管理、请求封装、目录结构
    Day 3 核心页面 首页列表、详情页、搜索页
    Day 4 功能完善 收藏、主题切换、本地缓存
    Day 5 性能调优 列表优化、图片优化、启动优化

    周末任务：完成剩余功能（设置页、空态、错误处理）；做一轮完整的测试和性能检查。

    第 10 周：复盘、面试整理与后续规划

    天数 主题 内容
    Day 1 知识复盘 整理前 9 周笔记，形成思维导图
    Day 2 性能专题总结 输出《RN 性能优化 20 条》
    Day 3 面试题整理 JS/React/RN 高频面试题
    Day 4 源码初探 阅读 React Native 一个核心模块源码
    Day 5 后续规划 新架构、TurboModules、Fabric 等方向

    周末任务：模拟一次技术面试（自我问答或录音）；把项目代码整理到 GitHub，写 README。
